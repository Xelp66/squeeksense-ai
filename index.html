How verification works ↗

A round starts at the next UTC half-hour boundary. After the full window ends, all 30-minute measurement buckets must be available before an outcome is scored. Missing data = unverified, never an automatic loss.

This is a playable, locally scored prediction experiment — not a trained neural network, token game, or shared leaderboard. Some Squeekchain API measurements may be simulated or replayed.
